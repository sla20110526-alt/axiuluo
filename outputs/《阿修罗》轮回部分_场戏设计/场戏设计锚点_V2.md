## 二、冻结事实

- 本段不是九个彼此无关的历史人物展示，而是同一个灵魂的因果链：**被看见 → 得到爱 → 被取代 → 妒恨 → 权力 → 报复 → 反噬 → 不悔 → 佛前归来**。
- 各世由同一演员／同一灵魂成立：眼型、眉骨、鼻唇关系、面部比例保持可认；年龄、发式、妆饰、身份可变化。
- 人间人物、建筑、道具全部电影写实，不继承佛国水墨人物规则。
- 全段共享冷寂、低饱和母体；压暗红、旧金、风雪蓝灰等颜色只能来自真实材料和物理光源，不使用整画面滤镜。
- PRP-003青绿落叶是全片唯一明确生命色：冷灰青绿、真实叶脉、轻微湿润、不发光；其色彩存在感不得被任何服装、火光或时代色超过。
- 镜头21—22共7秒必须允许幸福成立；镜头23起逐步加速；镜头29的4.5秒必须从高速轮回突然凝固。
- 动作接力必须清楚：伸来的手 → 发簪 → 握簪的掌心 → 推出毒酒 → 酒杯触案／落印合成一记重响 → 佛前合指握叶。
- 不在画面中显示历史姓名，不把真实历史女性简化为嫉妒或酷刑符号。
- 不出现直接伤害描写、血腥细节或猎奇死亡；力量来自选择、声画叠层和后果。
- 镜头29只能以听众剪影、肩线受光、垂手等层级建立佛的存在；不出现完整正面佛、不建立私人回应。
- 镜头29原始对白必须逐字保留：“因为无爱，所以无恨。”
- 镜头30原始VO必须逐字保留：“我的名字，叫阿修罗。”

## 四、当前场戏定义

- 开始状态：佛国的“被看见”被第一记人间心跳改写为一只具体伸来的手；她再次相信自己可能被一个人单独选择。
- 初始所得：镜头21—22中，她先被从人群边缘认出，再获得真实、短暂、可依靠的亲密。
- 核心缺口：她把“被爱”与“不可替代”绑定；一旦目击同一份温柔转向他人，失去被解释为自我被抹除。
- 主动升级：她从抓紧发簪、计算，走向借权力确保所有目光服从，再以落印和毒酒主动处置关系。
- 外化后果：宫门关闭、所欲之人被带走；火光、风雪、空床和多世死亡把报复的回力压回她自身。
- 结束状态：她回到佛前接住同一片叶，以平静微笑和合指把多世经验收回掌中；“因为无爱，所以无恨”是她此刻主动提出的生存结论，而非由佛替她认证的终极真理。
- 下游悬念：镜头30在黑场中由她自报名号，表明轮回没有抹去“我”，而是把它锻造成“阿修罗”。

## 六、场戏结构结果

### 6.1 场戏核心问题

当她终于得到一个人的真实注视，却发现这份注视可以转向别人，她能否承受“爱并不保证唯一”，还是会把爱改造成占有、权力与报复？

场戏给出的答案不是一句判断，而是一条完整可见的行动链：她先真实地得到爱，继而把被取代体验成自我被抹除；她不退出关系，而是抓住信物、调动权力、落印、递酒，直到关系和自身一起被反噬。多世失败没有使她求饶，最终她在佛前用“因为无爱，所以无恨”重新解释自己，并在合指握叶时保存住那个仍不肯消失的“我”。

### 6.2 三段结构

| 段落 | 镜头／时长 | 外部事件 | 内在转变 | 戏剧功能 |
|---|---:|---|---|---|
| 第一段：被选中与安住 | 21—22／7.0s | 一只手越过人群向她伸来；灯下两手相握，她靠在对方身侧 | 从“我是否被看见”进入“我终于被单独选择” | 必须让幸福真实成立，为后续失去提供同等真实的重量 |
| 第二段：唯一性崩塌与主动报复 | 23—27／12.5s | 同一动作／信物转向别人；握簪、登高位、落印、推酒、宫门关闭 | 被取代 → 计算 → 以权力替代亲密 → 主动处置 → 被自身选择反噬 | 证明她不是被命运单向伤害，而是在镜头26亲自跨过因果门槛 |
| 第三段：多世不悔与佛前自述 | 28—29／6.5s | 四种失败／死亡叠闪；高速骤停，她在佛前接叶、微笑、合指并说原文 | 受尽后果仍不求饶；把爱恨改写成自我保护性的结论 | 将多世压缩为一个稳定人格，并把片尾自报名号的力量蓄满 |

### 6.4 戏剧曲线与速度

- **00:00—00:07（镜头21—22）**：允许呼吸、触碰与身体重量完整发生。剪辑不能急于预告悲剧；观众必须先相信这是一段值得失去的温柔。
- **00:07—00:12.5（镜头23—24）**：以同一只手／同一发簪造成认知断裂。速度只抬一级，给“看见—确认—握紧—抬眼”留下清楚因果。
- **00:12.5—00:19.5（镜头25—27）**：权力、落印、毒酒、关门连续加速；每镜只保留一个决定性动作，避免把短时长剪成信息堆砌。
- **00:19.5—00:21.5（镜头28）**：速度达到峰值。四世不是四个完整小故事，而是四次“仍不低头”的证据；声音比画面更早融合成逼问。
- **00:21.5—00:26（镜头29）**：突然凝固。所有时代声响收束回佛国声场；接叶、微笑、合指和一句对白必须拥有真实时长，不能继续使用闪回速度。

### 6.5 场戏决定点与责任归属

- 镜头23是信息转折：她确认自己可被替代。
- 镜头24是心理门槛：受伤开始转为计算，但行动尚未完成。
- **镜头26是本场决定点**：落印与推酒都是她清醒完成的主动动作；从此“反噬”不能只解释为外界迫害。
- 镜头29是立场落点：她没有求佛裁决，也没有被佛赦免；她自己说出结论并合指保存叶片。

### 6.6 价值转变

- 起点价值：被看见／可能被选择。
- 短暂正值：得到爱／身体安住／相信唯一。
- 逆转：被取代／唯一性崩塌。
- 主动负值：以权力和报复替代亲密。
- 后果：所欲之人、归属、身份与生命反复失去。
- 终点价值：不求饶、不悔，但把“无爱”建立为防止再次被伤害的自我结论；“我”没有消失，反而成为片尾名号的核心。

### 6.7 结构控制线

1. 前7秒的温柔若不成立，后19秒只会成为情节罗列；镜头21—22不得压缩成预告式蒙太奇。
2. 镜头23—24必须让观众看懂她失去的不是一件首饰，而是“唯一性”的证明。
3. 权力不是角色欲望的终点，只是她强迫众人看见自己的代偿工具。
4. 镜头26必须把决定落在她的手上；不以哭喊、受逼迫或失控减轻主动性。
5. 镜头27—28呈现后果而不猎奇，且每次失败都要保留同一灵魂的抬眼动作。
6. 镜头29不判定她已经解脱；接叶、微笑、合指与原文共同保留“清醒、自护、执取”并存的复杂性。
