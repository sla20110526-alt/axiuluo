- 因果链固定为：被看见 → 得到爱 → 被取代 → 妒恨 → 权力 → 报复 → 反噬 → 不悔 → 佛前归来。
- 镜头21—22共7秒必须让幸福真实成立；镜头23—27逐级加速；镜头28为2秒速度峰值；镜头29在4.5秒内突然凝固。
- 镜头24为心理门槛；镜头26为本场唯一主动因果门槛。
- CHR-001是跨世面部总锚；年龄、发式、妆饰、服装、身份可变，眼型、眉骨、鼻唇关系、面部比例和真实肤质保持同一演员可认。
- 女主关键选择使用右手：镜头22相握、24握簪、26落印／推杯、29接叶／合指。
- 人间镜头21—28全部电影写实；镜头29回佛国后，CHR-001与CHR-010写实，GRP-001为明确中国水墨形态。
- PRP-003冷灰青绿落叶是唯一明确生命色，真实、不发光，镜头29合指后不碎。
- 不显示历史姓名；不展示中毒结果、伤口、血、死亡过程或猎奇酷刑。
- 镜头29佛不转头、不正面完整显现、不私人回应女主。
- 镜头29原台词逐字保留：女主／阿修罗同期轻声：“因为无爱，所以无恨。”
