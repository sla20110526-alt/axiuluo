# GPT Image 2.5｜人间轮回与色彩例外测试 Prompt

## 测试目的

验证人间轮回段能否在保持同一冷寂母体影调与写实材料的同时，容纳压暗的传统时代色，并让冷灰青绿落叶成为全片唯一明确生命色。

本测试使用匿名历史片段与中性服装，只验证项目级色彩、材质与跨时空身份关系，不形成正式轮回人物造型、历史建筑、镜头或资产设计。

## 平台与建议设置

- 平台：GPT Image 2.5
- 模型：优先 Sunburst
- 质量：`high`
- 画幅：优先21:9超宽幅；界面不支持时使用最宽横图

## 上传顺序

1. `图片/人物/阿修罗.png`：女主身份主参考。
2. `图片/人物/阿修罗多视图.png`：补充面部角度、发髻和身体比例。

不要上传佛国水墨群像或巨构样本，避免佛国人物的水墨存在规则进入人间段。

## 可直接复制的完整 Prompt

生成一张超宽幅电影画面，作为“人间轮回与色彩例外”的视觉测试。

这是一张全新的电影式时间蒙太奇，不是佛国画面，也不是传统绘画、海报、角色设定图或三联画。画面由三个匿名人间轮回片段在横向空间中自然交叠连接，没有明显分栏、边框或拼贴接缝。

### 参考图职责

图1《阿修罗.png》是女主身份主参考。

图2《阿修罗多视图.png》用于补充面部角度、发髻、头身比例和人物一致性。

三个轮回片段中的女性都必须被认作同一个演员、同一个灵魂：保持相同的眼型、眉骨、鼻唇关系、面部比例、黑发、真实肤质和清瘦体形基础；不因时代色彩改变肤色；不使用换脸、网红脸、塑料皮肤或不同女性代替轮回。可以用中性的服装状态和轻微年龄感区分片段，但不要建立精确年龄或正式造型。

### 整体视觉母体

整体保持冷寂因果现实主义：中低明度、中低对比、低饱和、稳定而有层次的冷感黑位、柔和高光过渡。画面约四分之三仍由近黑、炭灰、旧木灰、土灰、铁灰、灰白和真实肤色组成。

三个轮回片段虽然具有不同命运主色，但必须共享同一套冷静、真实、克制的电影影调，不能像使用了三套互不相关的滤镜。

人间段所有人物、建筑和物件全部保持真实肉身与真实材料质感。不要出现佛国群僧式水墨透明、水墨边缘破散或雾中消融。

### 横向轮回片段

画面左侧是匿名的幽暗内室。一位保持参考人物身份的年轻女性处于真实、克制的生活瞬间。空间由旧木、灰白丝麻、纸绢和一盏真实油灯或烛火构成。少量低饱和缃黄与旧金色只存在于灯焰照亮的织物、旧木和皮肤边缘上，形成全片唯一短暂的温暖，但不能变成金黄色滤镜、浪漫糖水光或华丽宫廷画面。

画面中部是压抑、冷硬的权力空间。同一女性身份处于深色漆木、暗色织物、氧化金属和低反光案面的环境中。命运主色为压暗的绛红、暗朱和少量赭金。红色只生长在旧染织物、漆面、印泥或器物局部，旧金只来自磨损金属和暗淡装饰，不能污染整张画面和人物肤色。

这一部分不是艳丽宫斗剧，不出现鲜红大面积服装、明亮黄金宫殿、精致珠宝堆砌或黑金商业大片质感。

画面右侧进入蓝灰风雪与铁灰环境。同一女性身份处于空旷、寒冷、真实的风雪空间或短促的雪中残片。色彩由浅靛、月白、蓝灰、缟白和铁灰构成。雪不是纯白发光背景，而具有风向、湿度、灰尘和真实空气纵深；暗部仍保留皮肤、织物与环境材料层次。

这一部分不能形成唯美仙侠雪景、蓝色滤镜、冰雪女王造型或宝石蓝天空。

三个片段通过人物相同的手部方向、相近的身体轮廓和逐渐加速的空间节奏连接，使其像同一执念穿过不同物质时代，而不是三个演员的古装换装展示。

### 色彩必须来自材料

所有命运色必须依附于真实物质和真实光源：暗红来自低饱和旧染织物、漆面或印泥；旧金来自氧化金属、磨损装饰和微弱灯光反射；蓝灰来自雪、天空漫射、铁器与寒冷空气；土褐来自尘土、木材、皮革和道路；人物肤色始终保持自然、统一，不随片段变成红脸、黄脸或蓝脸。

不要用全画面红色、金色、蓝色调色滤镜区分时代。

### 唯一生命色

在三个轮回片段即将汇合的画面最前方，出现一只属于同一女主的真实手掌。掌心中只有一片窄椭圆形的真实落叶。

落叶颜色为冷灰青绿色，具有真实叶脉、轻微湿润感和自然薄度。它面积很小，却是整张画面中最明确、最容易被感知的生命色。

落叶不发光，不透明发亮，不旋转，不散发粒子或能量。它不是翡翠、法器、魔法物体或视觉特效。

暗红、旧金和蓝灰都必须比这片冷灰青绿叶更加压暗、更加低饱和。除这片叶子外，画面中不要出现其他清晰绿色或高彩度颜色。

### 材质与真实感

所有材质必须彼此可辨：皮肤具有自然毛孔与柔和受光；丝麻、厚织物和旧布具有不同垂坠与纤维反应；漆木保留低调反光与磨损位置；金属具有重量、氧化和冷硬反射；雪、尘土、木材与纸绢保持各自真实表面；使用痕迹符合接触与环境，不统一做旧。

整体像真实布景、真实演员和真实材料拍摄出的克制电影画面，而不是3D渲染、游戏CG、古装短剧、仙侠海报或AI概念艺术。

### 必须避免

- 佛国建筑、佛祖、僧侣、水墨人物或水墨消散。
- 三个带边框的独立画格。
- 三套彼此割裂的综合色彩滤镜。
- 高饱和鲜红、亮金、宝石蓝、霓虹绿或紫色神秘光。
- 命运主色污染女主肤色。
- 女性直视镜头或进行服装展示式摆拍。
- 过度磨皮、蜡像脸、网格纹、摩尔纹和重复织物暗纹。
- 宣纸底纹、装饰性笔触、水墨粒子或画面溶解。
- 金色圣光、无来源轮廓光、HDR和人工电影海报光效。
- 可辨认的真实历史人物、政权标志、朝代文字、字幕、水印或界面元素。

## 回传检查项

1. 跨世是否仍是同一个人。
2. 时代色是否长在材料和真实光源上。
3. 三个片段是否共用同一母体影调。
4. 冷灰青绿叶是否成为唯一明确生命色。
5. 人间人物是否保持完全写实。

## 使用边界
